# 内嵌 AI SDK · 集成后功能清单

> 版本：v0.1（待确认） 日期：2026-09-11
> 定位：SDK 集成进业务系统后，**最终用户看到的产品形态、交互方式与功能边界**，按角色分组，标注实现里程碑（M1=Java MVP / M2=网关与治理 / M3=规模化）。

---

## 1. 产品形态总览

> **一句话**：业务系统页面里出现一排"意图按钮"（随页面内容智能显隐），点击即执行，结果以卡片内嵌返回——没有聊天框，参数靠上下文自动带入 + 表单补齐。

典型交互动线（以 CRM 客户详情页为例）：

```
客户详情页右侧出现「智能操作」按钮组
  ├─ 📊 分析此客户          ← 本地意图（L1/L2）
  ├─ 📝 生成跟进方案        ← 本地意图，可能缺参
  └─ 📦 查询供应链库存      ← 跨系统意图（装配网关后出现）
        │ 点击
        ▼
  自动带入上下文（客户ID、当前视图）→ 缺参时弹轻量表单 → 执行中状态提示
        ▼
  结果卡片内嵌展开（结论 + 数据表格 + 风险标记 + 数据来源）
        ▼
  复制 / 重新生成 / 👍👍 反馈
```

## 2. 业务用户功能（核心使用体验）

| 编号 | 功能 | 交互方式 | 里程碑 |
|------|------|----------|--------|
| F1.1 | **页面内嵌意图按钮组** | 按页面类型渲染对应意图按钮（客户页→客户意图），嵌在业务页面固定区域（如右侧栏/工具栏） | M1 |
| F1.2 | **上下文感知显隐** | 按当前页面实体与意图的上下文声明匹配，过滤出可用意图；不相关意图不出现 | M1 |
| F1.3 | 按角色显隐 | 按登录用户角色过滤意图（治理策略中的角色声明） | M2 |
| F1.4 | 全局意图入口（悬浮球/侧边栏） | 跨页面可用的高频意图集合，不依赖特定页面 | M2 · 待确认是否要做 |
| F1.5 | **动态提示徽标** | 意图按钮上叠加宿主业务事实（如「2 份合同即将到期」），按等级着色；只挂当前页面已装载的意图 | M2 |
| F1.6 | **个性化待办与建议** | 统一「下一步」区列出具体对象（合同/客户）+ 起因说明，点击直跑对应意图（参数由宿主带入）；按目标意图分组，**最多并列 5 个分组、每组默认收起**（只显示分组名 + 条数），点开展开为可翻页表格（事项 / 操作），条目多不刷屏；执行后按「补充要求重跑（`followups`）→ AI 推荐意图（`nextIntents`）→ 宿主待办」排列，越贴近本次结果越靠前；`followups` / `nextIntents` 由提示词约束（3~5 条、每条可直接执行），不再时有时无 | M2 |
| F2.1 | **一键执行（上下文带参）** | 点击按钮即执行；SDK 自动从页面采集意图声明的上下文（当前客户ID、选中记录等） | M1 |
| F2.2 | **参数补全表单** | 缺参时弹出 Schema 驱动的轻量表单（自动生成控件：日期选择/下拉/输入框），填写后继续执行 | M1 |
| F2.3 | 执行状态反馈 | 按钮态变化 + 阶段提示（分析中→推理中→查询数据中），MVP 为简化状态 | M1（流式阶段流 M2） |
| F2.4 | 取消执行 | 执行中可取消 | M2 |
| F3.1 | **结果卡片内嵌渲染** | 结构化卡片：文本结论 / 键值对 / 表格 / 列表，按 IntentSpec 输出契约渲染 | M1 |
| F3.2 | 卡片类型扩展 | 图表卡片、风险等级标记、建议操作按钮 | M2 |
| F3.3 | 结果操作 | 复制（M1）；导出图片/Excel、重新生成（M2） | M1/M2 |
| F3.4 | 数据来源展示 | 卡片折叠区显示"数据出自哪些工具调用/接口"，增强可信 | M2 |
| F4.1 | 补充要求输入 | 结果卡片下方轻量输入框："换个时间范围再算一次"——对同一意图带约束重跑（非自由聊天） | 待确认 · 建议 M2 |
| F5.1 | 我的执行历史 | 用户查看自己最近的意图执行记录与结果回看 | M2 |
| F5.2 | 结果评价反馈 | 卡片上 👍/👍 + 一句话问题反馈，回流评测库 | M2 |
| F5.3 | 意图不可用提示 | 未装网关时，跨系统意图不出现/置灰并说明原因，不静默失败 | M1 |

## 3. 业务开发者功能（集成体验）

| 编号 | 功能 | 交互方式 | 里程碑 |
|------|------|----------|--------|

| F6.5 | 前端意图组件 | JS SDK/Web Component：意图按钮组 + 表单 + 卡片渲染，业务页面插一行挂载代码 | M1（简版，静态页演示） |

## 7. 待确认的产品决策点

| # | 决策点 | 选项与建议 |
|---|--------|-----------|
| 1 | **意图入口形态** | 页面内嵌按钮组（推荐，贴合"无感智能化"）；是否加全局悬浮球（M2 再定） |
| 2 | **结果展示容器** | 页面内嵌卡片（推荐，短结果）；长结果（报告类）用侧滑抽屉或全屏——建议两种都支持，按 IntentSpec 渲染契约选择 |
| 3 | **是否保留"补充要求"输入** | 建议保留（F4.1，M2）——它是"去聊天框"与"灵活性"的平衡点：只能对当前意图结果追加约束重跑，不是自由对话 |
| 4 | **流式输出** | MVP 整卡返回（简单可靠）；M2 上流式阶段提示与打字机效果 |
| 5 | **执行历史是否 MVP 就要** | 建议 M2——MVP 用 JSONL 转录满足排查即可 |
