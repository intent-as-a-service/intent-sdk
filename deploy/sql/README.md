# 建表脚本

## 分两类，别混用

| 类别 | 表 | 归属 | 位置 |
| --- | --- | --- | --- |
| SDK 自有 | `intent_config`、`intent_spec`、`intent_executor` | 意图 SDK | `mysql/`、`postgresql/`、`oracle/`、`sqlserver/` 各一份 `intent-ddl.sql` |
| 宿主示例 | `crm_*` 业务表、`system_menu` / `system_role_menu` / `system_users` 种子 | ruoyi-office（宿主应用） | 根目录 `01-*`、`02-*`、`03-*` |

只有第一类是 SDK 交付物。换宿主系统时，第二类整份替换成宿主的菜单与权限初始化脚本，
SDK 侧零改动。

## 多方言

四份 `intent-ddl.sql` 语义等价，按宿主数据库选一份执行：

```bash
psql -f postgresql/intent-ddl.sql
sqlplus user/pass @oracle/intent-ddl.sql
sqlcmd -i sqlserver/intent-ddl.sql
mysql -u root -p db < mysql/intent-ddl.sql
```

方言映射：

| MySQL | PostgreSQL | Oracle | SQL Server |
| --- | --- | --- | --- |
| `bigint AUTO_INCREMENT` | `bigint GENERATED BY DEFAULT AS IDENTITY` | `NUMBER(19) GENERATED BY DEFAULT AS IDENTITY` | `bigint IDENTITY(1,1)` |
| `bit(1)` | `boolean` | `NUMBER(1)` | `bit` |
| `datetime` | `timestamp` | `TIMESTAMP` | `datetime2(3)` |
| `mediumtext` | `text` | `CLOB` | `nvarchar(max)` |
| `ON UPDATE CURRENT_TIMESTAMP` | 触发器 | 触发器 | 触发器 |
| `CREATE TABLE IF NOT EXISTS` | 原生支持 | PL/SQL 包装 | `IF OBJECT_ID(...) IS NULL` |

## 也可以完全不建表

SDK 内置零建表模式：`intent.host.storage=MEMORY`（默认）或 `FILE`
（JSON 文件持久化，`intent.host.spec-dir` / `config-dir` 指定目录）。

- 意图定义放 `classpath:intent/*.yaml`，启动即加载；
- 上架状态与角色配置写入内存或文件；
- 动态改意图 = 改 YAML 后重启，或走 `FILE` 模式的写接口。

建表的唯一收益是"后台可增删改意图并即时生效"。演示与 POC 建议先用零建表模式。
